# 三张图（待画）

README 里留的三个位置，画什么先写在这里，免得忘了想说什么：

1. **换壳不丢**
   左边：三个不同壳子（CLI / 聊天窗 / 语音）各自的图标，中间一条线连到同一本日记；
   右边：一句话——「换过五次壳子之后，打开还是同一本日记。」
   要点：记忆不属于任何一个壳子。

2. **换机搬走**
   一个目录打包成一个小方块，箭头指向另一台机器，落地后打开同一页。
   配字：一个目录就是全部记忆；sha256 校验，搬过去能验。

3. **预热命中对比**
   两条时间线：上面是「问了才查」，下面给「开口前就备好」；
   在时间线上标出「等检索」的那段空白和它消失的位置。
   主张只有一句：先想起来，再开口。

画法：简单线稿 + 两个色（深色底、青色线），不要插画感；图里不出现真人、真名。
